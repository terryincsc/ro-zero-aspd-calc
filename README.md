# RO 樂園攻速計算機

一個用於計算仙境傳說（RO）樂園版本的攻擊速度（ASPD）計算工具。

## 功能特點

### 核心功能
- **精確的 ASPD 計算**：依據遊戲內 Excel 公式實作，確保計算結果準確
- **支援全職業**：涵蓋所有職業（服事、劍士、盜賊等共 32 個職業）
- **完整武器系統**：支援所有武器類型及雙持系統
- **Buff 系統**：包含攻速藥水、天使之賜福、加速術、心神凝聚等多種 Buff
- **即時計算**：輸入數值後即時顯示最終 ASPD 結果

### 存檔管理
- **多存檔系統**：可建立多個角色配置並快速切換
- **自動儲存提示**：未儲存變更時會顯示提示標記
- **匯入/匯出**：支援 JSON 格式匯出與匯入，方便分享或備份
- **存檔重命名**：可自訂存檔名稱，便於管理
- **快捷鍵**：支援 `Ctrl+S` / `Cmd+S` 快速儲存

### 計算細節
- **素質系統**：區分 Base + 裝備點數，以及卡片/附魔/寵物加成
- **心神凝聚支援**：正確處理弓箭手系職業的心神凝聚加成
- **武器懲罰計算**：自動計算職業與武器的 ASPD 懲罰
- **遠程/近戰區分**：弓、樂器、鞭子使用不同的素質加成公式
- **詳細計算過程**：展開「計算過程明細」可查看完整計算步驟

## 使用方法

### 開啟計算機
1. 直接在瀏覽器中開啟 `ro_zero_aspd_calculator.html`
2. 無需安裝任何軟體或伺服器

### 基本操作
1. **選擇職業與裝備**：在頂部選擇職業、主手武器、副手裝備
2. **輸入素質**：填入角色的 AGI 和 DEX 數值
   - Base + 裝備點數：基礎素質 + 裝備提供的素質點數
   - 其他加成：卡片、附魔、寵物等提供的加成
3. **設定 Buff**：勾選目前角色擁有的 Buff 效果
4. **查看結果**：最終 ASPD 會即時顯示在結果區域

### 存檔功能
- **切換存檔**：使用頂部下拉選單切換不同的角色配置
- **新增存檔**：點選「+ 新增存檔」建立新的配置
- **儲存變更**：點擊「💾 儲存」按鈕或按 `Ctrl+S` 儲存當前配置
- **改名存檔**：點擊 ✏️ 按鈕可修改存檔名稱
- **匯入/匯出**：點擊 ⋯ 選單可進行匯入或匯出操作
- **刪除存檔**：在 ⋯ 選單中選擇「刪除此存檔」

## 計算公式說明

### ASPD 計算流程
1. **Base ASPD**：根據職業決定的基礎攻速
2. **武器懲罰**：主手武器的 ASPD 懲罰值
3. **副手懲罰**：副手裝備（盾牌或左手武器）的 ASPD 懲罰值
4. **Stat Bonus**：由 AGI 和 DEX 計算的素質加成
   - 近戰：`√(DEX²/5 + AGI²/2) / 4`
   - 遠程：`√(DEX²/7 + AGI²/2) / 4`
5. **Status Bonus**：`Σmod × AGI / 200`
6. **ASPD1**：`FLOOR(Base ASPD + 武器懲罰 + 副手懲罰 + Stat Bonus + Status Bonus)`
7. **ASPD2**：`FLOOR(ASPD1 + (195 - ASPD1) × 總ASPD%)`
8. **最終 ASPD**：`ASPD2 + 固定素質 ASPD`

### 特殊機制
- **心神凝聚**：使「Base + 裝備點數」欄位 ×1.12（僅限弓箭手系職業）
- **純白百合花 / 慈悲術**：取代天賜之福/加速術，不計入 Status Bonus
- **雙持系統**：刺客系職業可雙持武器，左手有專屬懲罰表
- **職業/武器限制**：部分 Buff 僅對特定職業或武器生效

## 技術實作

### 架構
- **單檔應用**：所有功能整合於單一 HTML 檔案中
- **純前端**：不需要後端伺服器，可離線使用
- **本機儲存**：使用 `localStorage` 儲存所有存檔資料

### 技術棧
- HTML5
- CSS3（CSS Custom Properties）
- Vanilla JavaScript（無框架依賴）
